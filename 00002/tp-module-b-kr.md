# kns2026-00002 Module B (3h)

## 1. 개요

### 가. 과제요약

“투어 in 서울”은 대한민국 수도 서울에서 열리는 다양한 축제와 문화행사를 쉽고 빠르게 확인할 수 있는 개인별 맞춤 투어 설계가 가능한 정보 플랫폼이다. 주어진 축제 정보를 확인하여 원하는 행사를 쉽게 빠르게 찾을 수 있고, 시민과 관광객을 위해 제공되는 다양한 투어 정보를 활용하여 서울의 다채로운 문화와 축제를 가깝게 즐길 수 있도록 돕는 사이트를 개발하여야 한다.

### 나. 과제 구성 및 경기 시간

- 과제는 총 3개의 모듈과 Team Challenge로 구성되어 있으며, 정해진 시간 내에 각 모듈을 완성하여 제출하여야 한다.

- 해당 모듈을 완성한 후에는 다음 모듈을 작업해도 된다.

- 해당 모듈의 제출 시간이 지난 뒤에는 제출된 파일은 변경할 수 없다.

## 2. 요구사항

### 가. 과제요약

- 선수는 클라이언트 측의 요구사항과 주 이용자층에 맞춰서 디자인 시안과 그에 맞는 퍼블리싱을 완료해야 한다.

- 메인페이지의 레이아웃은 일반 PC용 페이지와 반응형 웹 페이지로 제작하여야 한다.

- 메인페이지는 페이지의 특색과 포인트, 역할을 한눈에 알 수 있고 이용자가 페이지에 계속 머물 수 있게 유도할 수 있는 디자인과 기능이 있어야 한다.

### 나. 공통사항

- 채점 브라우저는 Chrome 브라우저로 채점한다.

- 선수는 “투어 in 서울”의 의미가 부각되는 심벌과 “투어 in 서울” 텍스트가 포함된 로고를 독창적으로 직접 디자인하여야 한다.

- 모든 페이지는 일반 PC용(1920x1080)으로 제작해야 하고, 메인페이지에 한해서는 일반 PC용과 모바일 버전(480px)으로 둘 다 작동될 수 있도록 제작해야 한다.

- 페이지 내에 존재하는 모든 `<img>` 태그에는 alt과 title 속성을 적용해야 한다.

- 페이지 내에 존재하는 모든 `<a>` 태그에는 임시링크(#)를 적용한다. (단, 서브 페이지가 구현된 경우에는 해당 서브 페이지로 이동할 수 있는 링크를 적용한다.)

- 선수는 HTML5와 CSS3로 페이지를 제작해야 하며, JavaScript, PHP를 사용하지 않아야 한다.

- 모든 텍스트는 가독성과 디자인 요소를 고려하여 디자인한다.

### 다. 페이지 구성

- 모든 페이지에는 헤더 영역과 푸터 영역이 포함되어야 한다.

- 메인 페이지 접속 시, 브라우저에 로딩 페이지가 약 5초간 보인다.

- 로딩 페이지는 동적 효과를 포함하고 있으며 사용자의 관심과 흥미를 유발할 수 있어야 한다.

- 메인페이지는 [비주얼 영역, 투어소식 영역, 투어안내 영역, 에디터 추천여행 영역, 투어 홍보영상 영역]이 포함된다.

- 메인페이지는 가로 크기를 기준으로 브레이크포인트(480px)에서 반응형으로 동작하여야 하고, 레이아웃이 화면을 벗어나거나 가로 스크롤이 생겨서는 안된다.

    - 메뉴 내비게이션이 햄버거(<img src="media/tp-images/BIN0001.bmp" width="30">) 형태로 변경되어 보여진다.

    - 햄버거 버튼을 클릭하면 햄버거 버튼(<img src="media/tp-images/BIN0001.bmp" width="30">)이 닫기 버튼(X)으로 변경되고 내비게이션 메뉴가 애니메이션 효과와 함께 나타나며, 상단 바 이외의 영역을 클릭하면 상단 바가 애니메이션 효과와 함께 사라진다.

- 메인메뉴의 ‘투어소개’를 클릭하면 서브 페이지로 이동되고, 서브페이지에는 [투어 in 서울 소개] 영역이 포함된다.

### 라. 공통 영역

#### ○ 헤더

- 헤더 영역은 [로고 이미지, 내비게이션, 검색, 로그인, 회원가입]이 보인다.

- 내비게이션은 과제도면을 참고하여 메인메뉴를 구성하여야 한다.

- 내비게이션은 세로 스크롤이 되더라도 페이지 상단에 고정되어야 하며, 다른 영역과 구분되어 보여져야 한다.

- 메뉴 내비게이션에는 사용자의 시선을 끌 수 있는 1개 이상의 효과가 적용되어야 한다.

- 로고 이미지를 클릭하면 메인페이지로 이동되어야 한다.

#### ○ 푸터

- 푸터 영역은 “B\_Module/footer.txt” 파일의 내용을 활용하여 제작한다.

- 푸터 영역에는 로고와 카피라이트, 3개 이상의 소셜미디어 아이콘을 포함하여야 한다.

- 로고 이미지를 클릭하면 메인페이지로 이동되어야 한다.

#### ○ 로그인 및 회원가입

- 헤더에 있는 [로그인] 버튼 또는 링크를 클릭하면, 로그인 폼이 포함된 모달이 나타나야 한다.

- 로그인 폼은 아이디와 비밀번호를 입력할 수 있는 필드와 [로그인] 버튼이 있어야 한다.

- 헤더에 있는 [회원가입] 버튼 또는 링크를 클릭하면, 회원가입 폼이 포함된 모달이 나타나야 한다.

- 회원가입 폼은 아이디, 비밀번호, 이름을 입력할 수 있는 필드와 [가입] 버튼이 있어야 한다.

### 마. 메인페이지(index.html)

#### ○ 비주얼 영역

- “B\_Module/visual/” 폴더에 제공된 텍스트와 “B\_Module/images/” 폴더에 제공된 이미지를 적절히 활용하여 홈페이지 특성에 부합할 수 있도록 구현한다.

- 슬라이드는 좌/우, 상/하, 페이드인-아웃 중 하나를 선수가 디자인에 맞게 구현하여야 한다.

- 비주얼 이미지 슬라이드는 총 3개의 이미지로 구성하며 자동모드와 수동모드로 설정할 수 있는 토글 버튼이 있어야 한다.

    - 수동모드 : 이전/다음 버튼이 나타나고 버튼을 클릭해서 슬라이드가 가능하여야 한다.

    - 자동모드 : 이전/다음 버튼이 사라지고 자동으로 슬라이드가 진행된다.

- 이미지는 [1→2→3→1→2→3→1→2→3⋯] 순서를 유지하며, 전환속도는 4초 이내로 한다.

- 슬라이드 되는 각각의 이미지마다 텍스트가 존재해야 하며, 텍스트도 이미지와 함께 4초 이내로 슬라이드 되어야 한다. (단, 텍스트는 이미지에 덧붙여 사용할 수 없고 독립적으로 슬라이드 되어야 한다.)

#### ○ 투어 소식 영역

- “B\_Module/투어소식/” 폴더에 제공된 텍스트와 이미지를 활용하여 제작한다.

- 총 4개의 영역[축제소식, 행사일정, 프로그램, 서울여행]으로 구성하여야 한다.

- [축제소식] 영역의 각 텍스트에 마우스 오버 시 해당 항목이 선택되었음을 알 수 있도록 하이라이트 처리하여 다른 텍스트와 구분되어 보여지도록 구현하여야 한다.

- [행사일정], [프로그램], [서울여행] 영역은 해당 이미지에 마우스를 오버하면 해당하는 텍스트가 이미지 위에 동적 효과와 함께 나타나야 하며, 마우스가 벗어나면 텍스트는 사라져야 한다.

- 모든 영역에는 [더보기] 버튼 또는 링크가 존재하여야 한다.

#### ○ 투어 안내 영역

- “B\_Module/투어안내/” 폴더에 제공된 텍스트를 활용하여 제작한다.

- 투어 안내 영역은 달력 영역과 탭메뉴 영역으로 구분하고, 달력은 2026년 8월을 기준으로 제작되어야 한다.

- 탭메뉴는 총 3개의 탭(전체, 축제&행사, 전시&공연)이 존재하며 해당 탭은 제공텍스트를 활용하여 다음의 내용을 나타낸다.

    - 전체는 해당 월에 개최되는 모든 행사 목록을 보여준다.

    - 축제&행사는 해당 월에 개최되는 축제&행사 목록을 보여준다.

    - 전시&공연은 해당 월에 개최되는 전시&공연 목록을 보여준다.

- 달력에는 축제&행사 또는 전시&공연이 있는 날은 별도 표시를 해주어 사용자가 해당 날짜에 축제&행사 또는 전시&공연이 있다는 것을 알 수 있도록 표시하여야 한다.

※ C모듈에서는 제공되는 json파일의 정보와 DB에 추가되는 정보를 표시하는 기능이 추가됨.

#### ○ 에디터 추천여행 영역

- “B\_Module/추천여행” 폴더 내의 이미지와 텍스트를 활용하여 제작한다.

- 초기화면은 첫 번째 이미지를 가운데 위치시켜 2개의 이미지가 보여지도록 구현한다.

- 화면에는 최대 3개의 이미지가 보여지는 형태로 총 8곳의 에디터 추천 여행지가 스크롤 되어 보여지도록 구현해야 한다.

- 스크롤 되는 동작은 마우스 휠 조절, 스크롤바 드래그가 아닌 이미지를 클릭하는 동작을 통해 스크롤 되도록 구현해야 한다. 이 때, 클릭한 이미지는 가운데로 스크롤 되며 해당 텍스트가 나타나야 한다.

- 자세한 동작은 “B\_Module/참고영상” 폴더의 scroll.mp4를 참고하여 제작한다.

※ 기능만 참고하고 디자인은 선수가 창의적으로 구성하여야 한다.

#### ○ 투어 홍보영상 영역

- “B\_Module/홍보영상” 폴더 내의 동영상을 활용하여 제작한다.

- 영상은 2개이며 초기화면은 첫 번째(1.mp4) 영상이 플레이되고 있다.

- [다음영상보기] 버튼이나 링크를 클릭하면 두 번째(2.mp4) 영상으로 전환되어 보여져야 하며, 버튼은 [이전영상보기] 버튼으로 변경되어야 한다.

- [이전영상보기] 버튼이나 링크를 클릭하면 첫 번째(1.mp4) 영상으로 전환되어 보여져야 하며, 버튼은 [다음영상보기] 버튼으로 변경되어야 한다.

- 모든 동영상 control panel은 보이지 않아야 하고 반복적으로 플레이 되어야 한다.

- 이전/다음 동영상으로 전환될 때는 사용자의 시선을 끌 수 있는 전환 효과가 존재해야 하며, 선수가 창의적으로 자유롭게 구현한다.

### 바. 서브페이지(sub.html) - 투어 in 서울 소개

- “B\_Module/sub” 폴더에 텍스트와 이미지를 활용하여 구현한다.

- 총 3개의 투어[전통문화&역사투어, K-컬처&트랜디투어, 도심야경&힐링투어] 중 하나를 선택할 수 있어야 하며, 선택 여부를 명확하게 알 수 있도록 구현한다.

- 3개의 투어 중 하나를 선택하면 전환 효과를 포함하여 해당 투어에 제공된 이미지와 텍스트를 모두 표시하여야 한다.

- 다른 투어를 선택하면 기존 이미지와 텍스트는 변경된 투어의 이미지와 텍스트로 변경되어야 한다.

- 이미지에 마우스를 오버하면 이미지의 이름이 표시되고 이미지에 동적인 효과를 주어야 한다.

## 3. 선수 유의사항

- 선수는 작업을 시작하기 전에 제공받은 ‘선수제공파일’을 반드시 백업을 한 후 진행하여야 한다.(선수의 실수로 제공파일을 수정하거나 삭제한 경우에도 다시 제공하지 않는다.)

- 선수는 직접 디자인한 심볼로고 시안 이미지(jpg 또는 png)를 제출한다.

- 선수가 작업한 내용이 웹브라우저에서 정상적으로 작동하는 데 필요한 모든 리소스(폴더 및 각종 파일)를 제출한다. (index.html, sub.html 파일을 열었을 때 정상 작동하여야 함)

- 모든 작업 파일을 B\_Module 폴더에 저장해야 한다.
