[코스 플래너 페이지 예시 — 두 개의 모드 탭]

▣ 모드 탭
- ① 최단경로 탐색   ② 코스 자동구성

▣ [최단경로 탐색] 탭
입력 : 출발 명소(셀렉트) / 경유지(셀렉트, 선택) / 도착 명소(셀렉트) / ‘경로 탐색’ 버튼
결과 예시 (출발 ‘해돋이 전망대’ → 도착 ‘도심 광장’) :
- 출발 : 해돋이 전망대
- 1) 강변 산책로  (도보 12분)
- 2) 골목 식당가  (도보 15분)
- 3) 도심 광장   (지하철 11분)
- 요약 : 총 소요 38분 · 구간 3개 · 방문 명소 4곳

▣ [코스 자동구성] 탭
입력 : 하루 가용시간(분) / 출발 명소 / 선호 테마(전체·당일치기·힐링·미식·액티비티) / ‘코스 자동구성’·‘이 코스 저장’ 버튼
결과 예시 (출발 ‘해돋이 전망대’ · 가용 300분 · 테마 ‘전체’) :
- 출발 : 해돋이 전망대
- 1) 강변 산책로  (이동 12분 · 체류 50분)
- 2) 중앙 전통시장 (이동 22분 · 체류 70분)
- 3) 도심 광장    (이동 38분 · 체류 40분)
- 요약 : 방문 3곳 · 총 소요 232분 · 총 만족도 215

▣ 교통망 지도 영역
- 명소(노드) 8개 · 노선(간선) 12개를 도식으로 표시, 계산된 경로/명소를 하이라이트
