# kns2026-00006 Module C (4h)

## 3. Module C

### 가. 선수이행사항

#### ○ 공통사항

- 메인 페이지는 일관성 있는 디자인과 사용자 편의성을 고려하여 주제에 부합하고, 짜임새 있게 제작한다.

- 선수는 제공된 파일을 참고하여 js 폴더에 script 파일을 생성하여 요구사항을 구현하여야 한다.

- 선수는 MySQL, PHP 등을 활용하여 사이트를 완성하고 필요한 경우 제공된 jQuery, jQuery UI, Bootstrap 등을 활용하여 UI를 구성할 수 있다.

- 모든 페이지는 바로가기 및 링크는 올바르게 작동해야 한다.

- 완성된 페이지는 Google chrome에서 정상적으로 작동하여야 한다.

- 코드에는 유지 및 보수가 용이하도록 반드시 용도와 목적을 분명하게 표시하여 주석(한글만 인정)을 각각 5개 이상씩 작성해야 한다.

- 모든 데이터는 JSON 및 localStorage를 활용하여 관리한다.

- 페이지 이동 시 새로고침 없이 상태가 유지되도록 구현한다.

- 모든 텍스트는 가독성과 디자인 요소를 고려해서 디자인한다.

- 제공된 json 파일은 DB에 등록되어 있어야 한다.

- 관리자 계정의 아이디는 ‘admin’, 비밀번호는 ‘1234’, 이름은 ‘관리자’ 이어야 한다.

#### ○ 회원가입

- 헤더 영역의 회원가입 버튼 또는 링크를 클릭할 시 아이디, 아이디 중복 확인 버튼, 비밀번호, 이름, 이메일, 전화번호 필드와 회원가입 버튼을 포함한 폼이 모달 팝업 형태로 나타난다.

- 회원이 접근 시 “이미 가입된 회원입니다.”라는 메시지를 보여주고 메인페이지로 이동한다.

- 입력데이터는 전부 입력되어야 하며, 전부 입력하지 않은 경우 회원가입이 되지 않아야 한다.

- 이메일, 비밀번호, 전화번호는 아래 유효성 검사를 적용한다.

  - 이메일 형식 검사 및 중복 가입 방지

  - 비밀번호 최소 4자 이상

  - 전화번호는 숫자만 입력 가능

- 유효성 검사 실패 시 입력 필드 하단에 오류 메시지를 출력한다.

- 회원가입 성공 시 “회원가입이 완료되었습니다”라는 메시지를 보여주고 메인페이지로 이동시킨다.

#### ○ 로그인

- 헤더 영역의 로그인 버튼 또는 링크를 클릭할 시 아이디, 비밀번호 필드와 로그인 버튼을 포함한 폼이 모달 팝업 형태로 나타난다.

- 아이디, 비밀번호를 입력하여 로그인할 수 있다.

- 잘못된 아이디 또는 비밀번호를 이용하여 로그인을 시도한 경우 “아이디 또는 비밀번호가 일치하지 않습니다” 라는 메시지를 보여준다.

- 로그인에 성공하면 헤더 영역의 로그인, 회원가입 버튼 또는 링크가 사라지고, ‘<이름>(<아이디>)’ 와 로그아웃 버튼 또는 링크가 나타난다.

- 로그인에 성공하면 “로그인이 완료되었습니다.”라는 메시지와 함께 메인페이지로 이동한다.

- 로그아웃 버튼을 누르면 정상적으로 로그아웃되어 헤더 영역에 다시 로그인과 회원가입 버튼 또는 링크가 나타난다.

- 로그인 세션(session)은 브라우저를 종료하거나 로그아웃하지 않는 한 유지되어야 한다.

#### ○ [전체 펫시터]

- 회원이 전체 펫시터를 확인할 수 있도록 제작된 페이지이다.

- “petsitter.json” 파일을 활용하여 구현한다.

- 카드 기능은 메인 페이지의 인기 펫시터 카드와 동일하게 구현한다.

- 펫시터 카드에는 프로필 사진, 이름, 지역, 평점, 리뷰 수, 재계약률, 가격, 예약 가능 상태 표시, 태그를 포함하고 ‘예약하기‘와 ’찜하기‘ 버튼을 제작한다.

- 상단에는 반려동물 종류별 카테고리(전체, 강아지, 고양이, 소동물, 특수 케어)를 구현한다.

- 태그 데이터를 활용하여 필터 시스템을 구현한다.

- 필터는 다중 선택이 가능해야 하며, 선택된 조건에 맞는 펫시터만 출력한다.

- 태그 필터 선택 시 페이지 새로고침 없이 목록이 실시간으로 변경되도록 구현한다.

- 예약 가능 여부를 표시하며, 예약 가능 상태에 따라 다른 스타일을 적용한다.

- 인기 펫시터에는 리뷰 수가 100개 이상, 평점이 4.5이상의 카드이며, 카드 상단에 ‘인기 펫시터’ 배지를 표시한다.

- 인기순, 평점순, 리뷰순 등의 정렬 기능을 제공한다.

- ‘찜하기’ 버튼 클릭 시 관심 펫시터로 등록할 수 있도록 제작한다.

- 페이지 상단에는 현재 출력 중인 펫시터 수를 표시한다.

- 이미 예약된 펫시터는 버튼이 비활성화 되어야 한다.

- 예약하기 버튼을 눌렀을 때 비로그인 상태이면 “로그인 후 이용해 주세요.”라는 메시지와 함께 전체 펫시터 페이지로 다시 이동하며, 로그인 상태이면 예약하기 페이지로 이동한다.

#### ○ [인기 펫시터]

- 회원이 인기 펫시터를 확인할 수 있도록 제작된 페이지이다.

- 메인 메뉴의 인기 펫시터 메뉴 또는 메인 페이지 인기 펫시터 영역의 더보기 버튼을 통해 이동할 수 있어야 한다.

- “petsitter.json” 파일을 활용하여 구현한다.

- 카드 기능은 메인 페이지의 인기 펫시터 카드와 동일하게 구현한다.

- 펫시터 카드에는 프로필 사진, 이름, 지역, 평점, 리뷰 수, 재계약률, 가격, 예약 가능 상태 표시, 태그를 포함하고 ‘예약하기‘와 ’찜하기‘ 버튼을 제작한다.

- 인기 펫시터에는 리뷰수가 100개 이상, 평점이 4.5이상의 카드만 보이게 한다.

- 이미 예약된 펫시터는 버튼이 비활성화 되어야 한다.

- 예약하기 버튼을 눌렀을 때 비로그인 상태이면 “로그인 후 이용해 주세요.”라는 메시지와 함께 인기 펫시터 페이지로 다시 이동하며, 로그인 상태이면 예약하기 페이지로 이동한다.

#### ○ [펫시터 지원]

- 회원이 펫시터에 지원할 수 있도록 제작된 페이지이다.

- 비로그인 상태에서 접근 시 “로그인 후 이용해 주세요.”라는 메시지와 함께 메인페이지로 이동시킨다.

- 페이지에는 이름, 나이, 전화번호, 활동 가능 지역, 보유 자격증, 지원 동기를 입력할 수 있는 필드, 돌봄 가능 동물 선택할 수 있는 필드와 태그(전체, 산책, 소형견, 노령견 케어, 고양이, 약 먹이기, 실내놀이, 방문돌봄, 대형견, 소동몰, 위탁돌봄, 24시간 케어, 병원동행, 특수케어 – 중복 선택 가능하게. 최대 3개)를 선택할 수 있는 필드, 가격을 입력할 수 있는 필드, 지원하기 버튼을 포함한다.

- 지원 동기 입력 시 글자 수를 실시간으로 표시한다.

- 모든 입력 항목은 필수로 입력되어야 하며, 미입력 항목이 있을 경우 지원이 진행되지 않아야 한다.

- 지원 완료 시 “펫시터 지원이 완료되었습니다.”라는 메시지와 함께 메인페이지로 이동시킨다.

#### ○ [예약하기]

- 회원이 펫시터를 예약할 수 있도록 제작된 페이지이다.

- 비로그인 상태에서 접근 시 “로그인 후 이용해 주세요.”라는 메시지와 함께 메인페이지로 이동시킨다.

- 페이지에는 이름, 전화번호, 반려동물 종류, 예약 날짜, 요청 사항을 입력할 수 있는 필드와 예약하기 버튼을 포함한다.

- 예약 날짜 선택 시 오늘 이전 날짜는 선택할 수 없도록 구현한다.

- 이미 예약된 날짜 선택 시 “이미 예약된 날짜입니다.”라는 메시지를 출력한다.

- 요청 사항 입력 시 글자 수를 실시간으로 표시한다.

- 모든 입력 항목은 필수로 입력되어야 하며, 미입력 항목이 있을 경우 예약이 진행되지 않아야 한다.

- 예약 완료 시 “펫시터 예약이 완료되었습니다.”라는 메시지와 함께 메인페이지로 이동시킨다.

#### ○ [돌봄 서비스]

- 회원이 돌봄 서비스를 신청할 수 있도록 제작된 페이지이다.

- 비로그인 상태에서 접근 시 “로그인 후 이용해 주세요.”라는 메시지와 함께 메인페이지로 이동시킨다.

- 페이지에는 보호자 이름, 전화번호, 반려동물 종류, 요청 서비스, 예약 날짜, 요청 사항을 입력할 수 있는 필드와 신청하기 버튼을 포함한다.

- 요청 서비스는 방문 돌봄, 방문 산책, 위탁 돌봄, 병원 동행 중 선택할 수 있도록 제작한다.

- 예약 날짜 선택 시 오늘 이전 날짜는 선택할 수 없도록 구현한다.

- 요청 사항 입력 시 글자 수를 실시간으로 표시한다.

- 모든 입력 항목은 필수로 입력되어야 하며, 미입력 항목이 있을 경우 신청이 진행되지 않아야 한다.

- 신청 완료 시 “돌봄 서비스 신청이 완료되었습니다.”라는 메시지와 함께 메인페이지로 이동시킨다.

#### ○ [마이페이지]

- 회원이 펫시터 예약/돌봄 서비스 신청 내역과 찜한 펫시터, 반려동물 정보 및 내 정보를 확인할 수 있도록 제작된 페이지이다.

- 회원은 자신의 예약내역과 신청 내역, 자신의 정보, 반려동물 정보를 조회할 수 있다.

- 내 정보에는 프로필 사진, 이름, 아이디, 이메일, 전화번호를 표시하며, 프로필 사진을 변경할 수 있도록 구현한다.

- 마이페이지 영역에는 [반려동물 정보 등록] 버튼을 배치한다.

- [반려동물 정보 등록] 버튼 클릭 시 반려동물 정보를 입력할 수 있는 모달 팝업이 나타난다.

- 모달 팝업에는 사진, 이름, 종류, 품종, 나이, 성별, 특이사항을 입력할 수 있는 필드를 포함한다.

- 등록 버튼 클릭 시 입력한 정보가 반려동물 프로필 영역에 출력되어야 한다.

- 반려동물 프로필에는 사진, 이름, 종류, 품종, 나이, 성별, 특이사항을 표시한다.

- 비로그인 상태에서 접근 시 “로그인 후 이용해 주세요.”라는 메시지와 함께 메인페이지로 이동시킨다.

- 반려동물 정보를 추가 및 수정할 수 있도록 제작한다.

- 내 정보 수정 버튼을 통해 회원 정보를 변경할 수 있도록 제작한다.

- 찜한 펫시터 영역에는 인기 펫시터 페이지에서 ‘찜하기’ 버튼을 클릭한 펫시터 카드가 모두 출력된다.

- 펫시터 예약에는 사용이 종료되지 않은 나의 모든 예약건이 목록(이름, 반려동물 종류, 예약날짜, 요청 사항) 형태로 보인다.

- 돌봄 서비스 신청 내역에는 사용이 종료되지 않은 나의 모든 신청 내역이 목록(이름, 반려동물 종류, 요청 서비스, 예약 날짜, 요청 사항) 형태로 보인다.

- 펫시터 예약 및 돌봄 서비스 신청 내역에는 취소 버튼을 포함하며, 취소 버튼을 누르면 모달 팝업이 뜨고 취소 사유를 입력할 수 있는 필드와 취소 버튼을 포함해 구현한다.

- 취소 버튼을 클릭하면 정상적으로 취소가 진행되어야 하며, “취소가 완료되었습니다.”라는 메시지를 출력한 뒤, 목록에서 삭제한다.

#### ○ 관리자 - [예약/신청 내역 관리, 회원 관리]

- 관리자가 예약/신청 내역을 조회하고 회원을 관리할 수 있도록 제작된 페이지이다.

- 관리자는 회원의 예약 내역과 신청 내역, 회원을 조회할 수 있다.

- 회원이 접근 시 “관리자 페이지입니다.”라는 메시지와 함께 메인페이지로 이동시킨다.

- 관리자는 가입된 모든 회원 정보를 조회할 수 있다.

- 회원 목록은 회원 이름, 아이디, 이메일, 전화번호, 가입일을 포함하여 출력한다.

- 회원 목록은 최신 가입순으로 정렬하여 출력한다.

- 회원 목록에는 삭제 버튼을 포함한다.

- 삭제 버튼 클릭 시 확인 모달 팝업이 나타나며, 삭제 버튼 클릭 시 해당 회원 정보를 삭제한다.

- 회원 삭제 완료 시 “회원이 삭제되었습니다.”라는 메시지를 출력한 뒤 목록에서 제거한다.

- 펫시터 예약에는 모든 예약건이 목록(회원 이름, 회원 아이디, 전화번호, 반려동물 종류, 예약날짜, 요청 사항) 형태로 보인다.

- 돌봄 서비스 신청 내역에는 모든 신청 내역이 목록(회원 이름, 회원 아이디, 전화번호, 반려동물 종류, 요청 서비스, 예약 날짜, 요청 사항) 형태로 보인다.

- 예약 및 신청 내역은 최신순으로 정렬하여 출력한다.

- 펫시터 예약 및 돌봄 서비스 신청 내역에는 취소 버튼을 포함한다.

- 취소 버튼을 클릭하면 정상적으로 취소가 진행되어야 하며, “취소가 완료되었습니다.”라는 메시지를 출력한 뒤, 목록에서 삭제한다.

#### ○ 관리자 - [펫시터 지원 관리]

- 관리자가 펫시터 지원 내역을 조회하고 관리할 수 있도록 제작된 페이지이다.

- 관리자는 회원의 펫시터 지원 내역을 조회할 수 있다.

- 회원이 접근 시 “관리자 페이지입니다.”라는 메시지와 함께 메인페이지로 이동시킨다.

- 지원 내역은 목록(회원 이름, 나이, 전화번호, 활동 가능 지역, 보유 자격증, 지원 동기, 돌봄 가능 동물) 형태로 보인다.

- 지원 내역에는 승인 및 거절 버튼을 포함한다.

- 승인 버튼 클릭 시 해당 회원은 펫시터로 등록되며, “승인이 완료되었습니다.”라는 메시지를 출력한다.

- 거절 버튼 클릭 시 “거절이 완료되었습니다.”라는 메시지를 출력한 뒤 목록에서 삭제한다.

- 승인된 해당 카드의 회원은 전체 펫시터 영역에 표시된다.

### 나. 선수유의사항

- 선수는 작업을 시작하기 전에 제공받은 ‘선수제공파일’을 반드시 백업을 한 후 진행하여야 한다. (선수의 실수로 제공파일을 수정하거나 삭제한 경우에도 다시 제공하지 않는다.)

- 작업 결과물은 Chrome 브라우저에서 정상적으로 실행되어야 한다.

- 선수는 XAMPP 구동과 관련된 모든 서비스(또는 프로세스)를 종료한 후, XAMPP 폴더 전체를 제출한다. 제출한 작품은 http://localhost/ 에서 정상 동작해야 한다.

- 선수는 스스로 제출한 최종결과물이 심사위원의 컴퓨터에서도 동일하게 작동할 수 있도록 보장해야 한다. 또한 심사위원 컴퓨터에서 경로 등의 문제로 정상 표시되지 않거나 작동에 이상이 있는 경우에도 이를 심사위원이 수정하지 않고 채점 기준에 따라 채점이 지행된다는 것을 유의한다.
