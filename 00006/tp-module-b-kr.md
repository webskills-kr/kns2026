# kns2026-00006 Module B (3h)

## 1. 개요

### 가. 과제요약

○ 숙련기술인을 위한 펫케어 플랫폼인 “스킬스 펫케어”를 제작하여, 펫시터 예약 및 돌봄 서비스를 이용하고자 하는 숙련기술인 및 일반 사용자를 위한 홈페이지를 구현하고자 한다. 해당 플랫폼은 펫시터 예약, 돌봄 서비스 신청, 펫시터 지원, 찜하기, 마이페이지 등의 기능을 제공하며, 사용자는 원하는 펫케어 서비스를 편리하게 이용할 수 있다.

### 나. 과제 구성 및 경기시간

- 과제는 총 3개의 모듈로 구성되어 있으며, 정해진 시간 내에 각 모듈을 완성하여 제출해야 한다.

- 해당 모듈을 완성한 후에는 다음 모듈을 작업해도 된다.

- 해당 모듈의 제출 시간이 지난 뒤에는 제출된 파일을 변경할 수 없다.

## 2. Module B

### 가. 선수이행사항

#### ○ 공통사항

- 메인 페이지는 일관성 있는 디자인과 사용자 편의성을 고려하여 주제에 부합하고, 짜임새 있게 제작한다.

- 선수는 “B-Module” 폴더의 텍스트(*.txt) 파일과 이미지 및 자료를 활용할 수 있다.

- 로고는 “펫시터 예약 플랫폼”을 시각적으로 표현하고, “믿고 맡기는 반려 돌봄, 함께하는 행복한 일상” 문구를 포함한 로고를 디자인한다.

- 로고 파일을 ‘logo.png’로 저장하여 제출한다.

- 모든 페이지는 1920px × 1080px 해상도(PC 버전)에 최적화하여 제작한다.

- 콘텐츠 영역의 최대 너비는 1320px로 제작한다.

- 모든 파일(*.html, *.css)에는 한글 주석이 각각 5개 이상 존재하여야 한다.

- 선수는 HTML5와 CSS3만을 사용하여 제작하며, Javascript는 사용하지 않는다.

- 모든 `<a>` 태그에는 임시 링크(#)를 지정해야 한다.

- 모든 `<img>` 태그에는 alt와 title 속성을 사용해야 한다.

- 모든 텍스트는 가독성과 디자인 요소를 고려해서 디자인한다.

- 선수는 과제에서 제시한 사항 이외에도, 사용자의 흥미와 관심을 가질 수 있는 상호작용 효과 및 애니메이션을 추가할 수 있다.

- 제출된 페이지는 Google Chrome에서 정상적으로 작동되어야 한다.

#### ○ 페이지 구성

- 모든 페이지에는 헤더 영역과 푸터 영역을 포함한다.

- 메인 페이지에는 [비주얼 영역, 인기 펫시터 영역, 예약 프로세스 영역, 후기 영역, SNS 갤러리 영역, FAQ 영역]이 포함된다.

- 서브 페이지에는 [서비스 소개 영역, 안심케어 및 안전 가이드 영역, 실시간 이용 현황 및 활동 지표 영역]이 포함된다.

- 위 이외의 영역을 선수가 임의로 추가할 수 있다.

#### ○ 공통영역

- 헤더 영역은 [로고 이미지, 내비게이션, 로그인, 회원가입]이 보인다.

- 로고 이미지를 클릭하면 메인페이지로 이동한다.

- 내비게이션은 [사이트 소개, 펫시터, 돌봄 서비스, 회원 서비스, 관리자]으로 구성되어 보여져야 한다.

- 내비게이션 메뉴 중 하나에 마우스를 올리면 해당 메뉴가 선택되었다는 효과를 보여준다.

- 서브메뉴가 있는 메인메뉴 클릭 시 서브메뉴가 애니메이션 되며 보여진다.

- 서브 메뉴가 펼쳐져 있을 때, 서브메뉴에 마우스를 올리면 하이라이트가 되고 마우스커서가 벗어나면 하이라이트를 해제한다.

- 마우스 커서가 서브메뉴에서 벗어나면, 펼쳐진 서브메뉴는 사라진다.

#### ○ 로그인

- 헤더영역에 로그인 버튼에 마우스를 올렸을 때 활성효과가 나타난다.

- 헤더영역에 있는 로그인 버튼을 클릭하면, 로그인 폼이 포함된 레이어 팝업이 자연스럽게 나타난다.

- [닫기/X] 버튼을 눌렀을 시 로그인 폼이 닫혀야 한다.

- 로그인 폼은 로그인 타이틀, 아이디와 비밀번호를 입력할 수 있는 암호상자와 [Login] 버튼, 3개 이상의 SNS 아이콘이 존재해야 한다.

- 로그인 폼 하단에는 “회원가입 바로가기” 링크를 배치한다.

#### ○ 비주얼 영역

- 비주얼 영역은 “B-Module/images” 폴더 내의 사진을 활용하여 사이트의 특성이 잘 나타나도록 디자인한다.

- 총 3개의 이미지를 사용하며, 3초 간격으로 자동 전환되도록 구현한다.

- 3개의 이미지가 순차적으로 전환되어야 한다. (1 ->2->3->1->2->3...)

- 이미지 전환 효과는 자유롭게 설정할 수 있다.

- 비주얼 영역에는 이미지 마다 각각 사이트의 주제를 나타내는 텍스트를 포함한다.

#### ○ 메인페이지

##### □ 인기 펫시터 영역

- 제공된 “B-Module/01-petsitter.txt” 파일을 사용한다.

- 인기 펫시터는 6명이상 출력한다.

- 펫시터 카드에는 프로필 사진, 이름, 지역, 평점, 리뷰 수, 재계약률, 가격, 예약 가능 상태 표시, 태그, 후기 문구를 포함하고 ‘예약하기’와 ‘찜하기’ 버튼을 제작한다.

- 제공된 태그 데이터를 활용하여 태그 시스템을 구현한다.

- 펫시터 카드에 마우스 오버 시 선택 효과를 적용한다.

- 후기 문구는 자동으로 전환되도록 제작한다.

- 영역 하단에는 더보기 버튼을 제작하며, 클릭 시 인기 펫시터 페이지(Module C)로 이동할 수 있어야 한다.

##### □ 예약 프로세스 영역

- 제공된 “B-Module/02-process.txt” 파일을 사용한다.

- 예약 진행 과정을 단계별로 안내한다.

- 프로세스는 4단계 이상으로 제작한다.

- 각 단계에는 아이콘, 단계 번호, 제목, 설명을 포함한다.

- 카드에 마우스 오버 시 해당 카드가 강조되도록 효과를 적용한다.

- 단계별 연결 흐름을 애니메이션으로 자연스럽게 표현한다.

##### □ 후기 영역

- 제공된 “B-Module/03-review.txt” 파일을 사용한다.

- 후기 영역은 슬라이드 형태로 “<”, ”>”을 사용하여 넘어가야 한다.

- 후기 카드는 4개 이상 제작한다.

- 후기 카드에는 사용자 프로필, 이름, 반려동물 종류, 별점, 후기내용, 날짜를 포함한다.

- 카드에 마우스 오버 시 해당 카드가 확대되고 나머지 카드는 축소되도록 제작한다.

- 슬라이드 이동 버튼은 슬라이드 애니메이션이 종료된 후에만 동작되어야 한다.

- 현재 슬라이드 위치를 확인할 수 있는 페이지 표시 요소를 제작한다.

##### □ SNS 갤러리 영역

- 제공된 “B-Module/gallery” 폴더 내에 이미지 파일과 “04-gallery.txt” 파일을 사용한다.

- 제공된 이미지 파일 중 사진 6장 이상을 사용하여 이미지 비율에 맞게 정렬한다.

- 갤러리 이미지는 사용자의 흥미를 끌 수 있도록 동일한 크기가 2개 이상 반복되지 않도록 한다.

- 카테고리 선택 메뉴[전체, 강아지, 고양이, 기타]를 제작한다.

- 각 게시물에는 좋아요 수, 해시태그를 포함한다.

- 게시물 클릭 시 팝업 형태로 확대되어 나타나야 한다.

- 팝업에 닫기 버튼을 누르면 팝업이 닫혀야 한다.

- 팝업에는 이미지, 좋아요 수, 해시태그, 사용자 아이디를 포함한다.

##### □ FAQ 영역

- 제공된 “B-Module/05-faq.txt” 파일을 사용한다.

- FAQ는 아코디언 형태로 제작한다.

- 질문 클릭 시 답변이 펼쳐져야 한다.

- 펼쳐진 질문은 강조되어 표시되어야 한다.

- 답변 영역은 자연스럽게 나타나야 한다.

- 하나의 질문이 펼쳐질 경우 다른 질문은 닫혀야 한다.

##### □ 푸터 영역

- 제공된 “B-Module/footer.txt” 파일을 사용하며 제공된 텍스트를 모두 이용한다.

- 푸터 영역에는 로고와 카피라이트가 존재해야 한다.

- 푸터 영역에는 3개 이상의 SNS 아이콘을 배치하며, 아이콘에 마우스를 오버 시 아이콘이 애니메이션 되는 효과를 자유롭게 구현한다.

- 서비스 바로가기 메뉴를 포함하여 제작하고, 링크 클릭 시 해당 영역으로 이동되도록 구현한다.

#### ○ 서브페이지

##### □ 서비스 소개 영역

- 제공된 “B-Module/06-about.txt” 파일을 사용한다.

- 제공된 텍스트들을 활용하여 디자인하되, 메인페이지 디자인과 일관성이 있어야 한다.

- 서비스 소개 문구와 이미지를 포함하여 제작한다.

- 서비스 특징을 설명하는 카드를 4개 이상 제작한다.

- 동적 효과가 최소 1개 이상 포함되어 있어야 한다.

##### □ 안심케어 및 안전가이드 영역

- 제공된 “B-Module/06-about.txt” 파일을 사용한다.

- 안전한 돌봄 서비스를 안내하는 영역으로 제작한다.

- 아이콘과 설명을 포함한 안내 카드를 제작한다.

- 카드에 마우스 오버 시 아이콘 또는 배경에 변화 효과를 적용한다.

### 나. 선수유의사항

- 선수는 작업을 시작하기 전에 제공받은 ‘선수제공파일’을 반드시 백업을 한 후 진행하여야 한다. (선수의 실수로 제공파일을 수정하거나 삭제한 경우에도 다시 제공하지 않는다.)

- 작업 결과물은 Chrome 브라우저에서 정상적으로 실행되어야 한다.

- 선수 결과물을 제출 할 경우 반드시 경로를 확인하여 파일이 정상적으로 작동되어야 한다.

- 제공된 파일 이외의 외부 파일 사용은 제한한다.

- 선수는 심볼로고 시안 이미지(jpg 또는 png)를 제출한다.

- 선수가 작업한 내용이 웹브라우저에서 정상적으로 작동하는 데 필요한 모든 리소스(폴더 및 각종 파일)를 제출한다.(index.html 파일을 열었을 때 정상 작동하여야 한다.)

- 모든 경로는 상대경로를 사용하여야 한다.
