# kns2026-00003 Module B (3h)

## 1. 요구사항

### 가. 개요

인천 시민의 불편함과 요구사항을 통합적으로 수렴하고, 이에 대해 함께 논의하며 해결해 나가는 시민 소통 페이지를 제작하려 합니다.

### 나. 과제 구성 및 경기 시간

- 선수는 제공된 도면과 파일을 이용하여, 과제에서 요구하는 사항을 모두 구현 하여야 한다.

- 과제는 총 3개의 모듈과 Team Challenge로 구성되어 있으며, 정해진 시간 내에 각 모듈을 완성하여 제출하여야 한다.

- 해당 모듈을 완성한 후에 다음 모듈을 작업해도 된다.

- 모듈의 제출 시간이 지난 뒤에는 제출된 파일은 변경할 수 없다.

### 라. 선수이행사항

#### ■ 공통사항

- 모든 페이지 내에는 헤더, 푸터 영역이 필수로 존재해야 하며, 모든 링크에는 임시 링크(#)를 적용한다. 단, 요구된 페이지로 이동하는 링크는 제외한다.

- 페이지에 존재하는 모든 이미지에는 alt와 title 속성이 존재해야 한다.

- 선수는 HTML5와 CSS3로 페이지를 제작해야 하며, JavaScript를 사용하지 않아야 한다.

- 선수는 작성 중인 HTML 파일과 CSS 파일에는 알아보기 쉬운 한글 주석을 작성해야 한다.

- 영역 구현은 문제에 나와있는 순서대로 제작하여야 한다.

- 완성된 페이지는 Google Chrome에서 정삭적으로 작동해야 한다.

### 마. 기능구현

#### ■ 페이지 구성

- B모듈은 비주얼 영역, 소개 영역, 공지사항 영역, 이용수칙 영역, 자주묻는 질문 영역이 있는 메인 페이지와, 베스트 게시판 영역, 베스트 토론 영역이 존재하는 서브 페이지가 존재해야한다.

- 위 영역 외에 영역은 선수가 임의로 추가가 가능하다.

- 메인 페이지는 “index.html”파일로 저장되어 제출되어야 한다.

#### ■ 모든 페이지 – 헤더 영역

- 헤더 영역은 모든 페이지에 있어야 한다.

- 헤더 영역에는 로고, 메뉴 내비게이션, 로그인 버튼 또는 링크, 회원가입 버튼 또는 링크를 포함하여 제작하여아 한다.

- 로고는 ‘인천 아카이브’텍스트와 직접 제작한 심볼을 포함하여 제작하여야 한다.

- 메뉴 내비게이션은 과제 도면을 참고하여 구성한다.

- 메뉴 내비게이션 내의 모든 메뉴는 마우스 오버 시 하이라이트 되어야 하고, 마우스 아웃 시 하이라이트가 해제되어야 한다.

- 서브 메뉴는 처음에 보이지 않는 상태이고 메인 메뉴에 마우스 오버 시 보여진다.

- 서브 메뉴를 오버 시 해당 메인 메뉴도 하이라이트 되어야 한다.

- 로고를 클릭 시 메인 페이지로 이동되어야 한다

- 헤더는 항상 페이지 상단에 고정되어 있어야 한다.

#### ■ 모든 페이지 – 푸터 영역

- 푸터 영역은 모든 페이지에 있어야 한다.

- 푸터 영역은 사용자가 제작한 로고와 제공된 ‘텍스트/footer.txt’파일의 내용과 카피라이트, SNS 아이콘 3개 이상을 활용하여 디자인한다.

- 푸터의 SNS 아이콘에 마우스 오버 시 하이라이트 되고, 마우스 아웃 시 하이라이트가 해제된다.

- 푸터의 로고를 클릭 시 메인 페이지로 이동된다.

- 푸터는 페이지 최하단에 있어야 한다.

#### ■ 메인 페이지 – 비주얼 영역

- 비주얼 영역은 헤더 영역을 제외하고 사이트 최상단에 존재한다.

- 비주얼 영역의 아이템은 제공된 ‘텍스트/visual.txt’파일의 내용과 제공파일의 ‘image/’에 있는 이미지로 구성되어야 한다.

- 비주얼 아이템은 3개 이상으로 제작되며, 비주얼 애니메이션은 [1-2-3-1-2-3-1-2...] 순서를 유지하며 사용자가 창의적으로 제작한다.

- 비주얼은 아이템이 넘어가는 애니메이션을 제외하고 또 다른 애니메이션이 존재해야 한다.

#### ■ 메인 페이지 – 소개 영역

- 소개 영역은 인천 아카이브를 소개하는 영역이다.

- 소개 영역에는 제공파일의 ‘image/’에 있는 이미지가 1개 이상 사용되어야 한다.

- 소개 영역에는 사용자의 흥미를 끌만한 애니메이션이 하나 이상 존재해야 한다.

- 소개 영역은 제공파일의 ‘텍스트/introduce.txt’의 내용을 활용하여 제작한다.

- 소개 영역은 메인 텍스트와 서브 텍스트를 `<hr>`을 사용하여 영역을 구분해야 한다.

#### ■ 메인 페이지 – 공지사항 영역

- 공지사항 영역은 페이지의 관리자가 사용자에게 적은 공지글을 모아놓은 영역이다.

- 공지사항 영역은 ‘텍스트/notice.txt’를 활용하여 제작한다.

- 공지사항 영역은 4개 이상의 아이템이 존재하여야 한다.

- 공지사항 영역의 각 아이템 제목을 클릭 시 게시글 자세히 보기 페이지로 이동되어야 한다.

#### ■ 메인 페이지 – 이용수칙 영역

- 이용수칙 영역은 페이지를 이용하며 지켜야 할 내용을 모아놓은 영역이다.

- 이용수칙 영역에 있는 각 아이템에는 아이콘이 존재해야 한다.

- 이용수칙 영역의 각 아이템에 있는 아이콘은 서로 달라야 한다.

- 이용수칙 영역에 있는 아이템에 마우스 오버하면 해당 아이템이 하이라이트 되어야 한다.

- 이용수칙 영역은 제공파일의‘텍스트/rule.txt’의 내용을 활용하여 제작한다.

- 이용수칙의 아이템은 4개 이상 존재하여야 한다.

#### ■ 메인 페이지 – 자주묻는 질문 영역

- 자주묻는 질문 영역은 사용자들이 관리자에게 자주 하는 질문을 모아놓은 영역이다.

- 자주묻는 질문 영역은 제공된 ‘텍스트/Inquiry.txt’파일의 모든 내용을 사용하여 작성하여야 한다.

- 자주묻는 질문 영역의 질문은 자동으로 무한슬라이드 되어 보여야 한다.

- 자주묻는 질문 영역의 슬라이드 되는 영역에 마우스를 오버 시 슬라이드가 멈춰야 한다.

- 자주묻는 질문 영역의 아이템에 마우스 오버 시 해당 아이템이 하이라이트 되어야 한다.

#### ■ 베스트 게시판 페이지 – 베스트 게시판 영역

- 베스트 게시판 영역은 사용자들이 작성한 게시글 중에 많은 좋아요를 받은 글이 모여있는 영역이다.

- 베스트 게시판 영역은 제공파일의 ‘텍스트/post.txt’파일의 내용을 모두 사용하여 작성하여야 한다.

- 베스트 게시판 영역의 게시글은 셀렉트 박스를 통해 좋아요를 기준으로 내림차순 또는 오름차순으로 정렬이 가능하다. (단, 처음에는 내림차순이 선택되어 있다.)

- 베스트 게시판 영역은 페이징 기능으로 제작하여야 한다.

- 페이징은 총 5페이지 까지 존재하며 한 화면에 10개씩 보여야 한다.

- 페이징은 이전 다음 버튼이 존재하지 않으며 페이지 번호 버튼을 누를 시에만 페이징이 가능하다.

- 베스트 게시판의 글들은 페이징 될때마다 애니메이션 효과를 보이며 나타난다.

- 베스트 게시판 영역 아이템의 제목을 클릭하면 게시글 자세히 보기 페이지로 이동한다.

#### ■ 게시글 자세히 보기 페이지 – 게시글 영역

- 게시판의 제목을 클릭 시 보이는 페이지이다.

- 게시글 영역에는 프로필 사진과 아이디, 등록일, 제목, 내용, 좋아요 수, 좋아요 버튼 또는 아이콘은 제공파일의“텍스트/detail.txt”를 활용하여 제작한다.

- 게시글 영역의 요소는 드래그로 선택 되어서는 안된다.

#### ■ 게시글 자세히 보기 페이지 – 게시글 댓글 영역

- 게시글 영역 하단에 존재하는 해당 게시글에 댓글을 달 수 있는 영역이다.

- 게시글 댓글 영역은 제공파일의“텍스트/detail.txt”를 활용하여 제작한다.

- 게시글 댓글 영역에는 회원의 프로필 사진과 아이디, 댓글 내용, 등록일이 존재하며 댓글은 등록일 기준으로 내림차순 정렬 되어있다.

- 게시글 댓글 영역에는 댓글 입력 폼과 등록 버튼이 존재한다.

#### ■ 베스트 토론 페이지 – 베스트 토론 영역

- 베스트 토론 영역은 사용자들이 토론한 대화중 많은 대화를 한 토론들을 모아놓은 영역이다.

- 베스트 토론 영역은 제공파일의 ‘텍스트/debate.txt’파일의 내용을 모두 사용하여 작성하여야 한다.

- 베스트 토론 영역은 페이징 기능으로 제작하여야 한다.

- 페이징은 총 5페이지 까지 존재하며 한 화면에 10개씩 보여야 한다.

- 페이징은 이전 다음 버튼이 존재하지 않으며 페이지 번호 버튼을 누를 시에만 페이징이 가능하다.

- 베스트 토론의 글들은 페이징 될때마다 애니메이션 효과를 보이며 나타난다.

- 베스트 토론 영역 아이템의 제목을 클릭하면 토론 자세히 보기 페이지로 이동한다.

## 2. 선수 유의사항

- 모든 작업 파일을 B\_Module 폴더에 저장해야 하며, 그 중엔 다음 파일이 포함되어야 한다.

- 심벌 로고 디자인 파일 - ‘logo.jpg’또는 ‘logo.png’

- 메인 페이지 디자인 원본 및 시안 - ‘main.jpg’

- 베스트 게시판 페이지 디자인 원본 및 시안 - ‘sub1.jpg’

- 베스트 토론 페이지 디자인 원본 및 시안 - ‘sub2.jpg’

- 메인 페이지의 퍼블리싱 파일 - ‘index.html’

- 베스트 게시판 페이지 퍼블리싱 파일 - ‘sub1.html’

- 베스트 토론 페이지 퍼블리싱 파일 - ‘sub2.html’

- 게시글 자세히 보기 페이지 퍼블리싱 파일 - ‘sub3.html’

- 토론 자세히 보기 페이지 퍼블리싱 파일 - ‘sub4.html’

- 그 외의 리소스 파일은 자유롭게 구성하여 배치하되, 웹 브라우저에서 정상적으로 장동하는 데 필요한 모든 리소스를 제출해야 한다. (html 파일을 열었을 때 정상 작동 해야한다.)
