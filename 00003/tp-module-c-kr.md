# kns2026-00003 Module C (4h)


## 가. 선수이행사항

#### ■ 공통사항

- 선수는 MySQL, PHP, JavaScript 등을 활용하여 홈페이지를 완성하고, 필요한 경우 제공된 jQuery, jQuery UI, Bootstrap 등의 기능을 활용하여 UI를 재구성 할 수 있다.

- 완성된 페이지는 Google Chrome에서 정상적으로 작동하여야 한다.

- 사용자 친화적인 URI(user-friendly URI)을 사용한다.

※ 잘못된 예시) https://localhost?page=info

※ 올바른 예시) https://localhost/info 또는 https://localhost/info.html

- 해당 과제엔 “관리자”, “일반회원”, “게시판 매니저”, “토론 매니저”의 회원등급이 존재한다.

- 사용자는 유저 데이터베이스에 관리자 계정을 추가하여야한다.

- 관리자 계정: 아이디 "admin" / 이름 "관리자" / 비밀번호 "1234"

## 나. 기능구현

#### ■ 회원가입 페이지 – 회원가입 영역

- 회원가입 페이지는 비회원만 접근 가능하다.

- 회원가입에는 아이디, 비밀번호, 이름, 프로필 사진, 회원가입 버튼이 존재하며, 모든 입력 요소는 필수요소이다.

- 회원가입은 모든 필수 입력 요소를 입력하지 않고 회원가입 시 alert 창으로 에러가 나타난다.

- 회원가입은 조건에 맞게 진행되어야 한다.

- < 회원가입 조건 >

  1) 아이디는 중복되면 안되며, 영문과 숫자만 사용하여 4 ~ 12 자로 입력 가능하다.

  2) 이름은 한글로만 입력 가능하다.

  3) 비밀번호는 영문과 숫자, 특수문자만 조합하여 8 ~ 12자로 작성한다.

  4) 프로필 사진은 이미지 형식의 파일만 가능하다.

- 위의 회원가입 조건을 충족하지 않고 회원가입 시 에러 메시지가 alert 창으로 나타난다.

- 위의 회원가입 조건을 충족하고 회원가입 시 회원가입이 완료되고 메인페이지로 이동된다.

#### ■ 로그인 페이지 – 로그인 영역

- 로그인 페이지는 비회원만 접근 가능하다.

- 로그인 페이지에는 아이디, 비밀번호, 로그인 버튼이 존재한다.

- 아이디 또는 비밀번호를 입력하지 않거나 사용자 정보와 맞지 않으면 alert로 에러가 나타난다.

- 로그인이 완료되면 메인페이지로 이동하고 로그인 버튼은 유저의 프로필 사진과 아이디로 바뀌고 회원가입 버튼은 로그아웃 버튼으로 바뀐다.

- 회원 계정은 동시에 하나의 창(브라우저)에서만 로그인 상태를 유지할 수 있습니다. 이미 로그인되어 있는 창이 있더라도, 새로운 창에서 동일한 계정으로 로그인하면 기존 창의 로그인은 만료(로그아웃)되고 가장 최근에 로그인한 창만 로그인 상태가 유지되어야 한다.
  
  예시(ex): 일반 브라우저 탭에서 로그인한 후, 시크릿 탭이나 다른 브라우저를 열어 동일한 계정으로 로그인하는 경우, 기존 브라우저의 로그인은 자동으로 풀리고 새로 로그인한 브라우저의 로그인만 유지된다.

- 로그아웃 버튼을 클릭 시 로그아웃 된 후 메인페이지로 이동한다.

#### ■ 게시판 페이지 – 게시판 영역

- 게시판 페이지는 사용자들이 등록한 게시글들이 보이는 페이지이다.

- 게시판 페이지에는 카테고리 선택 요소, 정렬 셀렉트 박스, 검색 창과 검색 버튼, 등록 버튼, 게시글 리스트, 페이징이 가능한 UI가 보인다.

- 게시글은 제목, 카테고리, 등록 일자, 좋아요 개수가 보여진다. 게시글의 제목을 클릭하면 해당 게시글의 자세히 보기 페이지로 이동된다.

- 등록 버튼을 누르면 게시글 등록이 가능한 모달이 나타난다. 모달에는 제목, 내용, 카테고리, 사진, 첨부파일, 등록 버튼이 존재한다.

- 게시글 등록은 로그인한 회원만 가능하다. 만약 비회원이 모달에 있는 등록 버튼을 클릭 시 게시글은 등록되지 않고 alert로 경고 메시지가 나타난다.

- 모달에 있는 요소들 중 제목, 내용, 카테고리는 필수 입력 요소이다. 해당 요소들은 입력하지 않고 등록 시 alert로 경고 메시지가 나타난다.

- 사진은 이미지 형식의 파일만 등록 가능하며, 첨부파일에는 한 번에 여러 개의 파일을 입력하여 등록할 수 있다.

- 필수 입력 요소를 입력 후 등록 버튼을 클릭 시 등록되었다는 메시지와 함께 게시글이 등록된다.

- 카테고리 선택 요소에는 전체, 공지사항, 여행, 정보, 스포츠, 공부, 먹거리, 자유가 있으며, 처음에는 “전체”가 선택 되어있어야 한다. (단, 일반 회원의 글 등록 모달 카테고리에는 여행, 정보, 스포츠, 공부, 먹거리, 자유만 존재한다.)

- 관리자는 글 등록 시 카테고리에 “공지사항”이 추가로 존재한다. 공지사항을 선택하고 게시글을 등록하면 게시글 리스트의 첫 번째 페이지 최상단에 고정되며 “공지사항”표시가 나타난다. 공지사항이 여러 개일 때에는 공지사항 등록일 기준으로 내림차순 정렬한다.

- 카테고리 선택 요소를 선택할 시 검색 버튼을 누르지 않아도 리스트가 즉시 변경되어야 한다.

- 검색창에 텍스트를 입력한 후 검색 버튼을 누르면 게시글 제목에 해당 텍스트가 포함되는 게시글이 나타난다. 아무것도 입력하지 않고 검색 시 모든 게시글이 나타난다.

- 카테고리를 선택하면 그 카테고리만 나타나고, 카테고리를 선택 후 검색하면 그 카테고리에 맞으면서 검색어가 포함된 게시글만 검색되어 나타난다.

- 정렬 셀렉트 박스에는 등록일 내림차순/오름차순, 좋아요 내림차순/오름차순이 있다. 처음에는 “등록일 내림차순”이 기본으로 선택 되어있어야 한다.

- 정렬 셀렉트의 선택 요소를 변경할 시 검색 버튼을 누르지 않아도 리스트가 즉시 변경되어야 한다.

- 게시글 리스트는 한 페이지에 10개씩 보여야 한다.

- 페이징 영역에는 이전 버튼(또는 아이콘), 다음 버튼(또는 아이콘), 그리고 현제 페이지를 기준으로 5개의 페이지 번호 버튼이 보여야 하며, 각 버튼을 눌러 페이징이 가능해야 한다.

- 관리자 또는 게시글 매니저 계정으로 로그인 시 게시글 리스트의 각 게시글에 “삭제”버튼이 보인다.

- “삭제”버튼을 클릭 시 해당 게시글은 삭제되며, 해당 게시글에 링크된 댓글과 좋아요 데이터도 전부 함께 삭제된다.

#### ■ 게시글 자세히 보기 페이지 – 게시글 영역

- 게시글 자세히 보기 페이지는 선택한 게시글의 상세 내용을 확인할 수 있는 페이지이다.

- 게시글 영역에는 게시글을 등록한 사용자의 프로필 사진과 아이디, 등록일, 제목, 내용, 등록한 첨부파일 이름, 사진, 좋아요 버튼(또는 아이콘), 게시글 좋아요 수가 존재한다.

- 사용자의 프로필 사진 또는 아이디를 클릭 시 해당 유저의 유저 정보 페이지로 이동된다.

- 게시글 자세히 보기 페이지에 표시되는 사진은 마우스 우클릭 금지 등 어떠한 방법으로도 다운로드가 불가능 해야한다.

- 등록한 첨부파일의 이름은 확장자명을 포함하여 표시되어야 하며, 해당 첨부파일의 이름을 클릭하면 파일이 다운로드 된다.

- 게시글 좋아요 버튼 또는 아이콘을 클릭 시 좋아요 수가 1 증가하고, 좋아요가 활성화(클릭) 되었다는 시각적 효과를 보여준다.

- 활성화된 좋아요 버튼 또는 아이콘을 다시 클릭 시 좋아요 수가 1 감소하고, 활성화되었던 시각적 효과가 사라진다.

#### ■ 게시글 자세히 보기 페이지 – 게시글 댓글 영역

- 게시글 댓글 영역에는 댓글을 작성할 수 있는 입력 폼과 등록 버튼, 그리고 사용자들이 작성한 댓글 리스트가 존재한다.

- 게시글의 댓글은 비회원이 등록할 수 없다. 비회원이 등록 버튼을 클릭 시 alert로 경고 메시지를 표시하고 메인 페이지로 이동된다.

- 댓글 입력 폼에 내용을 입력하지 않고 등록 버튼을 클릭 시 alert로 에러 메시지가 나타난다.

- 내용을 입력하고 등록 버튼을 클릭 시 등록되었다는 메시지와 함께 댓글이 등록되며, 댓글 리스트에 방금 등록한 댓글이 추가된다.

- 댓글 리스트는 기본적으로 등록 일자 내림차순(최신순)으로 정렬되어 표시된다.

- 댓글에는 댓글을 입력한 사용자의 프로필 사진과 아이디, 댓글 내용, 등록 일자, 좋아요 버튼(또는 아이콘), 좋아요 수가 존재한다.

- 사용자의 프로필 사진 또는 아이디를 클릭 시 해당 유저의 유저 정보 페이지로 이동된다.

- 댓글의 좋아요 버튼 또는 아이콘을 클릭 시 좋아요 수가 1 증가하고, 좋아요가 활성화(클릭) 되었다는 시각적 효과가 나타난다.

- 활성화된 좋아요 버튼 또는 아이콘을 다시 누를 시 좋아요 수가 1 감소하고, 활성화되었던 시각적 효과가 사라진다.

#### ■ 토론 페이지 – 토론 영역

- 토론 페이지는 사용자가 토론 주제를 개설하면 여러 사용자들이 참여하여 토론할 수 있는 페이지이다.

- 토론 영역에는 토론 생성 버튼, 토론 리스트, 정렬 셀렉트 박스, 검색창과 검색 버튼, 페이징이 가능한 UI가 보인다.

- 토론 리스트에는 토론 제목, 등록일, 의견 수가 표시된다.

- 이미 종료된 토론의 경우, 어떤 의견으로 종료되었는지에 따라 제목 옆에 (찬성) 또는 (반대) 표시가 함께 보여야 한다.

- 토론의 제목을 클릭하면 해당 토론의 자세히 보기 페이지로 이동된다.

- 관리자 또는 토론 매니저 계정으로 로그인 시 토론 리스트의 각 토론에 “삭제”버튼이 보인다. 단, 종료된 토론은 삭제가 불가능하다.

- “삭제”버튼을 클릭 시 해당 토론이 삭제되며, 해당 토론에 작성된 의견 데이터도 전부 함께 삭제된다.

- 토론 생성 버튼을 클릭 시 토론을 생성할 수 있는 모달이 나타난다. 모달에는 토론의 제목을 입력할 수 있는 요소와 생성 버튼이 존재한다.

- 토론 생성은 로그인한 회원만 가능하다. 만약 비회원이 모달에 있는 생성 버튼을 클릭 시 alert로 에러 메시지를 표시하며 생성이 차단된다.

- 제목을 입력하지 않거나 이미 존재하는 동일한 토론 제목이 있을 때 생성 버튼을 클릭 시 alert로 에러 메시지가 나타난다.

- 토론 제목을 올바르게 입력 후 생성 버튼을 클릭 시 생성되었다는 메시지와 함께 토론 리스트에 등록한 토론이 추가된다.

- 검색창에 텍스트를 입력한 후 검색 버튼을 누르면 토론 제목에 해당 텍스트가 포함되는 토론만 필터링 되어 나타난다.

- 정렬 셀렉트 박스에는 등록일 내림차순/오름차순, 의견 수 내림차순/오름차순이 있으며, 처음에는 “등록일 내림차순”이 기본적으로 선택되어 있어야 한다.

- 정렬 셀렉트의 선택 요소를 변경할 시 검색 버튼을 누르지 않아도 리스트가 즉시 변경되어야 한다.

- 토론 리스트는 한 페이지에 10개씩 보여야 한다.

- 페이징 영역에는 이전 버튼(또는 아이콘), 다음 버튼(또는 아이콘), 그리고 현재 페이지를 기준으로 5개의 페이지 번호 버튼이 보여야 하며, 각 버튼을 눌러 페이징이 가능해야 한다.

#### ■ 토론 자세히 보기 페이지 – 논쟁 영역

- 논쟁 영역은 선택한 토론의 상세 내용을 확인하고 실시간으로 의견을 나눌 수 있는 영역이다.

- 토론 자세히 보기 페이지에 진입하면 즉시 찬/반 투표 모달이 나타난다.

- 모달에는 해당 토론의 제목이 표시되며,“찬성”버튼과 “반대”버튼이 존재한다. 두 버튼 중 하나를 클릭하면 모달이 닫힌다.

- 찬성 또는 반대 선택은 로그인한 회원만 가능하다. 비회원이 버튼을 클릭 시 alert로 에러 메시지를 표시하고 메인 페이지로 이동된다.

- 논쟁 영역에는 토론의 제목, 등록 일시, 의견 리스트, 의견을 작성할 수 있는 입력 요소와 “작성”버튼이 존재한다.

- 토론 의견 입력 요소에 아무것도 입력하지 않고 작성 버튼을 클릭 시 alert로 에러 메시지가 나타난다.

- 내용을 입력하고 작성 버튼을 클릭 시 의견이 작성되었다는 메시지와 함께 의견이 리스트에 반영된다.

- 이미 종료된 토론의 경우, “작성”버튼이 비활성화(disabled) 되어 있어야 한다.

- 의견은 한 줄에 하나씩 배치되며, 등록 일시 기준 오름차순(과거순)으로 정렬되어 표시된다.

- 의견에는 작성한 사용자의 프로필 사진과 아이디, 등록 일시, 해당 회원의 찬/반 투표 현황(선택 결과), 의견 내용이 표시된다.

- 화면 UI 배치 시, 자신이 작성한 의견은 오른쪽에 정렬되어야 하고 다른 사용자의 의견은 왼쪽에 정렬되어야 한다.

- 사용자의 프로필 사진 또는 아이디를 클릭 시 해당 유저의 유저 정보 페이지로 이동된다.

- 논쟁 영역의 의견 리스트에는 데이터가 실시간으로 동기화되어, 다른 사용자가 의견을 등록하더라도 즉시 화면에 나타나야 한다.(단, 사용자의 화면에 alert 창이 띄워져 잇는 상황 동안은 채점하지 않는다.)

#### ■ 문의 사항 페이지 – 문의 사항 영역

- 문의 사항 페이지는 일반 회원이 관리자에게 궁금한 점이나 건의 사항을 작성하고 확인할 수 있는 페이지이다.

- 문의 사항 영역에는 등록 버튼, 문의 사항 리스트, 그리고 페이징이 가능한 UI가 보인다.

- 문의 사항 리스트에는 문의 사항의 제목과 등록 일자가 표시되며, 기본적으로 등록 일자 내림차순(최신순)으로 정렬된다.

- 글 등록 시 비공개 옵션을 선택한 경우, 작성자와 관리자를 제외한 다른 사용자에게는 해당 문의 사항이 노출되지 않아야 하며 리스트에 “비공개”표시가 나타나야 한다.

- 관리자가 답변을 등록한 문의 사항은 리스트의 제목 옆에 “답변완료”표시가 보여야 한다.

- 문의 사항 리스트의 제목을 클릭하면 해당 문의 사항의 자세히 보기 페이지로 이동된다.

- 등록 버튼을 클릭 시 문의 사항을 작성할 수 있는 모달이 나타난다. 모달에는 제목, 내용, 이미지를 입력할 수 있는 요소와 등록 버튼, 비공개 선택 체크박스(인풋)가 존재한다.

- 문의 사항 등록은 로그인한 회원만 가능하다. 만약 비회원이 모달에 있는 등록 버튼을 클릭 시 alert로 에러 메시지를 표시하며 등록이 차단된다.

- 입력 요소 중 제목과 내용은 필수 입력 요소이다. 필수 요소를 입력하지 않고 등록 버튼을 클릭 시 alert로 에러 메시지가 나타난다.

- 필수 입력 요소를 올바르게 작성하고 등록 버튼을 클릭 시 등록 완료 메시지와 함께 문의 사항 리스트에 추가된다.

#### ■ 문의 사항 자세히 보기 페이지 – 문의 상세 영역

- 문의 사항 자세히 보기 페이지는 선택한 문의 사항의 상세 내용과 이에 대한 관리자의 답변을 확인할 수 있는 페이지이다.

- 일반 문의 사항과 달리 비공개 문의 사항은 해당 글을 등록한 작성자 본인과 관리자만 상세 보기 페이지에 진입할 수 있다.

- 문의 상세 영역 내에서 사용자의 프로필 사진 또는 아이디를 클릭 시 해당 유저의 유저 정보 페이지로 이동된다.

- 문의 상세 영역에는 문의 사항의 제목, 내용, 등록 일자, 문의 사항을 등록한 사용자의 프로필 이미지와 아이디가 표시된다. 만약 글 등록 시 이미지를 첨부했다면 이미지도 함께 화면에 보인다.

- 관리자가 해당 문의 사항에 답변을 등록한 경우, 사용자 문의 내용 밑에 배치되며 관리자 프로필 사진, 관리자 아이디, 등록 일자, 답변 글(내용)과 함께 “관리자의 답변”표시가 보여야 한다.

#### ■ 문의 사항 자세히 보기 페이지 – 문의 댓글 영역

- 문의 사항 자세히 보기 페이지 하단의 댓글 영역에는 사용자가 댓글을 작성할 수 있는 입력 폼과 등록 버튼, 그리고 등록된 댓글 리스트가 존재한다.

- 문의 사항의 댓글은 비회원이 등록할 수 없다. 비회원이 등록 버튼을 클릭 시 alert로 에러 메시지를 표시하고 메인 페이지로 이동된다.

- 비공개로 등록된 문의 사항 글 내에서는 댓글 등록 버튼이 비활성화(disabled) 처리되어 있어야 한다.

- 댓글 입력 폼에 내용을 입력하지 않고 등록 버튼을 클릭 시 alert로 에러 메시지가 나타난다.

- 내용을 올바르게 입력하고 등록 버튼을 클릭 시 댓글이 정상적으로 등록되며, 댓글 리스트에 방금 등록한 댓글이 추가된다.

- 일반 사용자가 작성한 댓글은 기본적으로 등록 일자 내림차순(최신순)으로 정렬되어 표시된다.

- 댓글에는 댓글을 입력한 사용자의 프로필 사진과 아이디, 댓글 내용, 등록 일자가 표시된다.

- 관리자가 작성한 댓글은 일반 댓글의 등록 일자 내림차순 규칙을 무시하고, 댓글 리스트의 최상단에 무조건 고정되어 보여야 하며 “관리자”표시가 함께 나타나야 한다.

- 문의 댓글 영역 내에서 사용자의 프로필 사진 또는 아이디를 클릭 시 해당 유저의 유저 정보 페이지로 이동된다.

#### ■ 유저 정보 페이지 – 유저 정보 영역

- 유저 정보 페이지는 특정 회원의 프로필 사진이나 아이디를 클릭했을 때 해당 회원의 상세 정보와 활동 내역을 확인할 수 있는 페이지이다.

- 대상 회원의 프로필 사진, 이름, 아이디, 해당 회원이 작성한 누적 데이터 수(게시글 수, 토론 수, 문의 사항 수, 댓글 수)가 표시된다.

- 타인의 유저 정보 페이지일 경우, 해당 회원을 대상으로 하는 “팔로우”버튼과“차단”버튼이 존재한다.

- 로그인하지 않은 비회원이 “팔로우”또는“차단”버튼을 클릭 시, alert로 에러 메시지를 표시한 후 메인 페이지로 이동된다.

- 로그인한 회원이 “팔로우”버튼을 클릭 시 해당 회원이 팔로우 처리되며, 버튼은 “팔로우 취소”로 변경된다.

- 내가 팔로우한 회원이 게시글 또는 토론을 등록할 경우, 사이트 내 어느 페이지에 있든 화면 오른쪽 하단에 실시간으로 토스트 알림이 3초간 표시되어야 한다.

  - 게시글 작성 시) “(팔로우된 회원 아이디)님이 게시글을 작성하였습니다.”
  - 토론 생성 시) “(팔로우된 회원 아이디)님이 토론을 생성하였습니다.”

- “팔로우 취소”버튼을 클릭 시 팔로우가 취소되었다는 메시지와 함께 팔로우 상태가 해제되며, 버튼은 다시 “팔로우”로 변경된다.

- “차단”버튼을 클릭 시 “(차단된 회원 아이디)님이 차단되었습니다.”라는 메시지가 alert로 표시되고, 버튼 텍스트가“차단해제”로 변경된다.

- “차단해제”버튼을 클릭 시“(차단 해제된 회원 아이디)님의 차단이 해제되었습니다.”라는 메시지가 alert로 표시되며 차단 상태가 해제된다.

- 특정 회원에게 차단당한 유저가 자신을 차단한 회원의 게시글 상세 페이지 또는 토론의 자세히 보기 페이지에 접근을 시도할 경우, “해당 (게시글/토론)에 참여할 권한이 없습니다.”라는 메시지를 alert로 표시한 후 이전 페이지로 돌아간다.

#### ■ 관리자 페이지 – 회원 관리 영역

- 회원 관리 영역은 관리자 전용 공간으로, 전체 가입 회원의 정보를 모니터링하고 특정 회원에게 관리 권한을 부여하거나 계정을 삭제할 수 있는 영역이다.

- 해당 페이지는 관리자(admin) 계정으로 로그인했을 때만 접근이 가능하다.

- 관리자가 로그인에 성공하면, 헤더 내비게이션에 관리자 페이지로 이동할 수 있는 “관리자”링크 또는 버튼이 보인다.

- 회원 리스트는 기본적으로 가입일 기준 내림차순(최근 가입순)으로 정렬되어 표시된다.

- 회원에는 회원의 프로필 사진, 이름, 아이디, 가입일, “게시판 매니저”버튼, “토론 매니저”버튼, “삭제”버튼이 존재한다.

- 리스트 내에서 회원의 프로필 사진 또는 아이디를 클릭하면 해당 유저의 유저 정보 페이지로 이동된다.

- “게시판 매니저”버튼을 클릭 시 해당 유저의 등급이 변경된다. 화면상에서 기존 매니저 관련 버튼들은 사라지고 “일반 회원”버튼이 나타나며, 회원 아이디 옆에“게시판 매니저”표식이 명확하게 표시된다.

- “토론 매니저”버튼을 클릭 시 해당 유저의 등급이 변경된다. 화면상에서 기존 매니저 관련 버튼들은 사라지고 “일반 회원”버튼이 나타나며, 회원 아이디 옆에 “토론 매니저”표식이 명확하게 표시된다.

- 매니저 상태에서 “일반 회원”버튼을 클릭 시 등급이 다시 일반 회원으로 바뀐다. 화면에서 “일반 회원”버튼과 아이디 옆의 매니저 표식이 사라지고, 기존의 “게시판 매니저”및“토론 매니저”승급 버튼이 다시 노출된다.

- 회원 리스트에서 “삭제”버튼을 클릭 시 해당 회원의 계정 정보가 시스템에서 완전 삭제된다.

- 계정이 삭제됨과 동시에 해당 회원이 등록했던 모든 게시글, 댓글, 토론(의견 포함), 문의 사항 데이터가 데이터베이스에서 함께 전부 삭제 처리되어야 한다.

- 만약 삭제된 회원이 현재 사이트에 로그인하여 활동 중인 상태라면, 즉시 로그아웃 처리하고 “해당 계정은 관리자에 의해 삭제되었습니다.”라는 alert 경고창을 띄운 후 메인 페이지로 이동한다.

#### ■ 관리자 페이지 – 문의 사항 답변 영역

- 문의 사항 답변 영역은 관리자 전용 공간으로, 일반 회원들이 접수한 문의 사항들을 모니터링하고 이에 대한 답변을 작성 및 관리할 수 있는 영역이다.

- 해당 페이지는 최고 관리자(admin) 계정으로 로그인했을 때만 접근이 가능하다.

- 관리자가 로그인에 성공하면, 헤더 내비게이션에 관리자 페이지로 이동할 수 있는 “관리자”링크 또는 버튼이 보인다.

- 답변 대기 중인 문의 사항을 먼저 처리할 수 있도록, 리스트는 기본적으로 등록일 기준 오름차순(오래된 순)으로 정렬되어 표시된다.

- 답변이 완료된 문의 사항은 리스트 상에서 제목 옆에“답변완료”표시가 나타나야 한다.

- 리스트에서 문의 사항을 클릭하면 답변을 작성할 수 있는 모달이 나타난다. 모달 내부에는 답변을 입력할 수 있는 요소와 “답변”버튼이 존재한다.

- 답변 입력 요소는 필수 입력 사항이다. 내용을 입력하지 않고 답변 버튼을 클릭 시 alert로 에러 메시지를 표시하며 등록이 차단된다.

- 내용을 올바르게 입력하고 답변 버튼을 클릭 시, 답변 작성이 완료되었다는 alert 메시지를 출력한다.

- 이미 답변이 완료된 문의 사항은 리스트에서 클릭하더라도 답변 모달이 열리지 않아야 하며, 해당 글의 문의 사항 자세히 보기 페이지로 이동되어야 한다.

#### ■ 게시판 매니저 페이지 – 게시판 회원 관리 영역

- 게시판 회원 관리 영역은 게시판 매니저 전용 공간으로, 게시글을 작성한 회원들의 리스트를 모니터링하고 불량 이용자의 게시글 생성 권한을 일시적으로 제한(밴) 및 관리할 수 있는 영역이다.

- 해당 페이지는 게시판 매니저 권한을 가진 계정으로 로그인했을 때만 접근이 가능하다.

- 게시판 매니저가 로그인에 성공하면, 헤더 내비게이션 영역에 게시판 매니저 페이지로 이동할 수 있는 “게시판 매니저”링크 또는 버튼이 존재한다.

- 회원 리스트에는 게시글을 작성한 이력이 있는 회원의 프로필 사진, 아이디, 이름이 표시된다.

- 일반 상태인 회원 옆에는 “이용금지”버튼이 노출되며, 현재 이용금지(밴) 상태인 회원 옆에는 “이용금지”버튼 대신 “취소”버튼이 보인다.

- 회원 리스트에서 “이용금지”버튼을 클릭 시 정지 기간을 설정할 수 있는 모달이 나타난다. 모달 내부에는 1일부턴 7일까지 선택할 수 있는 기간 선택 요소(셀렉트 박스 등)와 “이용금지”버튼이 존재한다.

- 모달에 기간 선택 후 “이용금지”버튼을 클릭 시, 해당 회원의 게시글 작성 권한이 제한되었다는 안내 메시지가 표시되며 모달이 닫히고 리스트의 버튼이 “취소”로 전환된다.

- 이용금지 기간은 조치를 취한 당일부터 날짜를 계산한다.

  - ex) 1월 1일에 7일 정지 처분을 받은 경우, 1월 8일부터 게시글 작성이 가능해진다.

- 이용금지 처분을 받은 유저가 게시판 영역에서 글 등록 모달의 “등록”버튼을 클릭할 경우, “해당 서비스는 이용금지 상태입니다. (이용 가능 일자)부터 활동 가능합니다.”라는 에러 메시지를 alert로 표시하며 등록을 차단한다.

- 회원 리스트에서 이용금지 상태인 유저의 “취소”버튼을 클릭 시, 이용금지가 해제되었다는 메시지와 함께 회원의 글 작성 권한이 복구되며 버튼은 다시“이용금지”로 전환된다.

#### ■ 토론 매니저 페이지 – 토론 회원 관리 영역

- 토론 회원 관리 영역은 토론 매니저 전용 공간으로, 토론을 생성한 회원들의 리스트를 모니터링하고 불량 이용자의 토론 개설 및 토론 참여(의견작성) 권한을 일시적으로 제한(밴) 및 관리할 수 있는 영역이다.

- 해당 페이지는 토론 매니저 권한을 가진 계정으로 로그인했을 때만 접근이 가능하다.

- 토론 매니저가 로그인에 성공하면, 헤더 내비게이션 영역에 토론 매니저 페이지로 이동할 수 있는 “토론 매니저”링크 또는 버튼이 존재한다.

- 회원 리스트에는 토론을 생성한 이력이 있는 회원의 프로필 사진, 아이디, 이름이 표시된다.

- 일반 상태인 회원 옆에는 “이용금지”버튼이 노출되며, 현재 이용금지(밴) 상태인 회원 옆에는 “이용금지”버튼 대신 “취소”버튼이 보인다.

- 회원 리스트에서 “이용금지”버튼을 클릭 시 정지 기간을 설정할 수 있는 모달이 나타난다. 모달 내부에는 1일부터 7일까지 선택할 수 있는 기간 선택 요소와“이용금지”버튼이 존재한다.

- 모달에 기간 선택 후“이용금지”버튼을 클릭 시, 해당 회원의 토론 생성 및 의견 작성 권한이 제한되었다는 안내 메시지가 표시되며, 모달이 닫히고 리스트의 버튼이 “취소”로 전환된다.

  - ex) 1월 1일에 7일 정지 처분을 받은 경우, 1월 8일부터 토론 생성 및 의견 작성이 가능해진다.

- 이용금지 처분을 받은 유저가 토론 영역에서 토론 생성 모달의 [생성] 버튼을 누르거나, 토론 자세히 보기 영역에서 의견 [작성] 버튼을 클릭할 경우 “해당 서비스는 이용금지 상태입니다. (이용 가능 일자)부터 활동 가능합니다.”라는 에러 메시지를 alert로 표시하며 동작을 차단한다.

- 회원 리스트에서 이용금지 상태인 유저의 “취소” 버튼을 클릭 시, 이용금지가 해제되었다는 메시지와 함께 회원의 토론 생성 및 의견 작성 권한이 복구되며 버튼은 다시“이용금지”로 전환된다.

#### ■ 마이페이지 – 등록한 게시글 영역

- 마이페이지에는 로그인한 회원이 본인의 계정 정보와 활동 내역을 관리하는 공간으로, 등록한 게시글 영역에는 자신이 작성한 글들을 확인, 수정 및 삭제할 수 있다.

- 해당 페이지는 로그인한 회원만 접근 가능하다.

- 등록한 게시글 영역에는 본인이 작성하여 등록한 게시글들이 기본적으로 등록일 기준 내림차순(최신순)으로 정렬되어 표시된다.

- 게시글 리스트의 각 항목에는 게시글 제목, 등록일, 좋아요 수,“수정”버튼,“삭제”버튼이 존재한다.

- 게시글 제목을 클릭하면 해당 게시글의 자세히 보기 페이지로 이동된다.

- “삭제”버튼을 클릭 시 삭제 완료 메시지와 함께 해당 게시글이 삭제되며, 이와 동시에 해당 글의 좋아요 및 댓글 데이터도 전부 함께 삭제(연쇄 삭제)된다.

- “수정”버튼을 클릭 시 게시글을 수정할 수 있는 모달이 나타난다. 모달 내부에는 제목, 내용, 카테고리, 사진, 첨부파일 입력 요소와 “수정”버튼이 존재한다.

- 모달이 열릴 때, 모든 입력 요소에는 해당 게시글을 이전에 등록 혹은 수정했을 때 저장되어 있던 기존 값들이 그대로 입력(입력 폼에 세팅)되어 있어야 한다.

- 입력 요소 중 제목, 내용, 카테고리는 필수 입력 사항이다. 필수 요소를 입력하지 않고 “수정”버튼을 클릭 시 alert로 에러 메시지를 표시하며 처리를 차단한다.

- 모든 필수 값을 올바르게 입력하고 “수정”버튼을 클릭 시 해당 게시글의 데이터가 정상적으로 업데이트된다.

#### ■ 마이페이지 – 등록한 토론 영역

- 마이페이지의 등록한 토론 영역에서는 본인이 개설한 토론 주동 항목들을 확인하고, 투표 현황 모니터링 및 토론 종료, 삭제 등의 관리를 수행할 수 있다.

- 해당 페이지는 로그인한 회원만 접근이 가능하다.

- 등록한 토론 영역에는 본인이 개설한 토론들이 기본적으로 등록일 기준 내림차순(최신순)으로 정렬되어 표시된다.

- 등록한 토론 리스트의 각 항목에는 토론 제목, 등록일, 찬/반 비율, “삭제”버튼이 존재한다.

- 토론의 제목을 클릭하면 해당 토론의 자세히 보기 페이지로 이동된다.

- “삭제”버튼을 클릭 시 삭제 완료 메시지와 함께 해당 토론이 삭제되며, 이와 동시에 해당 토론에 작성된 모든 의견 데이터도 전부 함께 삭제된다.

- 해당 토론에 진입하여 찬성 또는 반대를 선택한 후 의견까지 작성한 사용자 수를 기준으로 찬/반 비율을 계산하여 백분율(%)로 표시한다.

- 의견을 작성한 총 인원이 5명 이상일 때만 찬/반 비율 중 더 높은 비율 쪽의 버튼(찬성 또는 반대)이 리스트 화면에 노출된다. (단, 찬성과 반대의 비율이 완전히 같을 경우에는 버튼이 나타나지 않는다.)

- 노출된 “찬성”또는“반대”버튼을 클릭하면 종료 완료 메시지와 함께 해당 토론이 종료된다. 종료된 토론은 상세 페이지에서 더 이상 의견을 작성할 수 없도록 마감 처리된다.

- 종료된 토론은 마이페이지 리스트 및 메인 토론 영역 리스트 상에서 어떤 의견으로 종료되었는지에 따라 제목 옆에 (찬성) 또는 (반대) 표시가 보여야 한다.

#### ■ 마이페이지 – 등록한 문의 사항 영역

- 마이페이지의 등록한 문의 사항 영역에서는 본인이 작성한 문의 글들을 확인하고, 관리자의 답변 여부에 따라 글을 수정하거나 삭제할 수 있는 영역이다.

- 해당 페이지는 로그인한 회원만 접근이 가능하다.

- 등록한 문의 사항 영역에는 본인이 작성한 문의 글들이 기본적으로 등록일 기준 내림차순(최신순)으로 정렬되어 표시된다.

- 문의 사항 리스트의 각 항목에는 문의 사항 제목, 등록일, “수정”버튼, “삭제”버튼이 포함된다.

- 글 등록 시 비공개 옵션을 선택했던 글에는 제목 옆에 “비공개”표시가 나타나야 한다.

- 관리자의 답변이 등록된 문의 글에는 제목 옆에 “답변완료”표시가 나타나며, 일반 상태와 달리“수정”버튼과 “삭제”버튼이 화면에서 보이지 않아야 한다.

- 문의 사항의 제목을 클릭하면 해당 글의 문의 사항 자세히 보기 페이지로 이동한다.

- 답변이 달리지 않은 상태에서 “삭제”버튼을 클릭 시 삭제 완료 메시지와 함께 해당 문의 글이 삭제된다.

- 문의 사항이 삭제됨과 동시에 해당 글에 달린 모든 댓글 데이터도 전부 함께 삭제 처리되어야 한다.

- “수정”버튼을 클릭 시 문의 사항을 수정할 수 있는 모달 팝업이 열린다. 모달 내부에는 제목, 내용, 이미지 입력 요소와 “수정”버튼이 존재한다.

- 모달이 열릴 때 모든 입력 요소에는 등록하거나 수정 시 저장했던 기존 값들이 그대로 입력되어 있어야 한다.

- 입력 요소 중 제목과 내용은 필수 입력 사항이다. 필수 요소를 입력하지 않고 “수정”버튼을 클릭 시 alert로 에러 메시지를 표시하며 수정을 차단한다.

- 모든 필수 값을 올바르게 입력하고 “수정”버튼을 클릭 시 수정 완료 메시지와 함께 데이터가 정상적으로 업데이트된다.

## 다. 선수 유의사항

- 선수는 작업을 시작하기 전에 제공받은 ‘선수제공파일’을 반드시 백업을 한 후 진행하여야 한다.(선수의 실수로 제공파일을 수정하거나 삭제한 경우에도 다시 제공하지 않는다.)

- 선수는 xampp 구동과 관련된 모든 서비스(또는 프로세스)를 종료한 후, xampp폴더 전체를 압축하여 심사위원이 배포한 USB안에 C\_Module 폴더에 저장하여야 한다.

- 선수는 최초 제출한 결과물에서 누락된 파일 또는 경로설정 오류 등으로 인해 발생하는 문제점에 대하여 기기 또는 저장매체의 오류로 인한 것이 아닌 한 재제출을 허용하지 않음에 유의한다.

- 선수는 경기 종료 후 파일이 담긴 USB를 제출하여야 하며 경기 종료 후 파일을 USB에 담는 것은 인정하지 않음에 유의한다.
